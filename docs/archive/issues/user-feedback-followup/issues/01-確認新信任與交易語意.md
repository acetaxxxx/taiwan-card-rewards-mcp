# 01: 確認新信任與交易語意

**What to build:** 將使用者已核可的產品語意正式記錄為可供後續實作依循的決策：私有 `user_confirmed` 優惠、單一 Transaction 記錄、多層付款路徑由 Offer Rule selector 驅動、以及 FX 相容鍵重用。使用者與 Agent 能從文件一致理解哪些資料是私有、哪些可共用，以及 planned recommendation 和 actual Transaction 的邊界。

**Blocked by:** None (can start immediately).

**Status:** completed

- [x] 決策紀錄明確修訂或取代既有「官方來源是私有規則唯一啟用門檻」的假設，保留來源可追溯性與租戶隔離。
- [x] 單一 Transaction 與回饋事件關聯的責任邊界已定案，並說明它如何延續事件生命週期與退款語意。
- [x] Offer Route Selector、Payment Capability、Generated Route 與 durable Payment Route Record 的角色及資料所有權一致且無互相矛盾的說法。
- [x] Agent 使用指南與 glossary 使用相同詞彙，且不宣稱尚未實作的契約已存在。
