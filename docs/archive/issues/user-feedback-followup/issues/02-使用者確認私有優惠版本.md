# 02: 使用者確認私有優惠版本

**What to build:** 使用者在對話中更正優惠條件時，Agent 先展示差異；使用者明確確認後，MCP 建立只屬於該使用者的不可變 Rule Version。後續推薦會使用新版本並清楚標示 `user_confirmed`，而官方查證可在不阻塞使用者流程下補強。

**Blocked by:** 01: 確認新信任與交易語意.

**Status:** completed

- [x] 未經使用者確認的更正保持 candidate 或僅供本次試算，不會持久化啟用。
- [x] 確認後建立私有新版本；撤銷與再次更正建立版本鏈，既有 Transaction 不被改寫。
- [x] 推薦與優惠查詢可顯示 trust basis、確認時間與來源摘要，且不將使用者確認說成官方驗證。
- [x] 不同使用者與公共優惠互相隔離；重試具冪等性，同一優惠家族不會重複計算回饋。
- [x] Public MCP contract accepts the complete preview/confirmation/write/recommend flow through calculate_reward and upsert_offer; regression tests cover the durable boundary.
