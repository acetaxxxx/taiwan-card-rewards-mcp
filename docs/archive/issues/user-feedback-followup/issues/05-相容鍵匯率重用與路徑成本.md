# 05: 相容鍵匯率重用與路徑成本

**What to build:** 推薦在相同清算脈絡下跨卡或跨候選重用 FX Snapshot，並在不同換匯主體、定價種類、卡組織或時效不相容時維持隔離。使用者可看見每條付款路徑的估算狀態、費用與淨值依據。

**Blocked by:** 04: 由優惠細則生成付款路徑.

**Status:** completed

- [x] FX 相容性同時比較幣別與方向、conversion owner、conversion timing、rate type、provider 或 card scheme 及新鮮度窗口。
- [x] route edge、route、card 或 issuer 的精確 scope 優先於可重用的通用 scope。
- [x] 相同 JCB 或等效清算條件的候選只需一筆新鮮報價；銀行、錢包、DCC 與不同卡組織不得錯誤共用。
- [x] 過期報價只會顯示為 estimate 並回傳 refresh action；actual Transaction 不可將它當成已結算匯率。
- [x] 公開整合測試驗證重用、隔離、scope 覆蓋、估算降級與排序成本差異。
