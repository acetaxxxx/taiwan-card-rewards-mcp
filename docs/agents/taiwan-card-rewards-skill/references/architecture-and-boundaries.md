# 架構與系統邊界規範 (Architecture & Boundaries)

**規範版本**：v0.9.0
**適用架構**：MCP 伺服器與 Agent Workspace 雙層架構

---

## 1. 系統權責邊界劃分 (Separation of Concerns)

本系統採行嚴格的雙層分工架構：**MCP Server（計算與狀態權威）** 與 **Agent Workspace（研究與互動代理）**。

```
┌─────────────────────────────────────────────────────────────────────────┐
│                      Agent Workspace (代理人工作區)                       │
│  - 使用者對話互動與偏好引導                                             │
│  - 外部網路檢索 (銀行官網、PDF條款、最新促銷公告)                        │
│  - 實體消歧義引導 (向使用者確認商家、方案或未結交易)                     │
│  - 外幣匯率取得與 PPM (百萬分之一) 數值量化                              │
│  - 證據階層化審查 (Primary Official vs Lead-Only Community)             │
└────────────────────────────────────┬────────────────────────────────────┘
                                     │ JSON-RPC (stdio)
                                     ▼
┌─────────────────────────────────────────────────────────────────────────┐
│                     MCP Server (計算與持久化權威)                         │
│  - 零網路 (Zero Network)：絕不主動發起外部連線或 HTTP 請求               │
│  - 純粹數學計算：四捨五入、無條件進位/捨去、步進值計算                   │
│  - 多組件回饋分解：Base Rate + Multiplier + Stacked Bonus               │
│  - 上限池與週期性帳本扣減：月結制、日結制、活動全期上限追蹤             │
│  - 實體與合約驗證：ULID 產生、Schema 封閉性檢查、敏感欄位攔截           │
│  - 租戶專屬檔案持久化：Exclusive Lock、交易冪等寫入與退款對沖           │
└─────────────────────────────────────────────────────────────────────────┘
```

## 2. 邊界不變量清單 (Boundary Invariants)

| 維度 | MCP Server 職責 | Agent Workspace 職責 | 嚴格禁止事項 (Forbidden) |
|---|---|---|---|
| **網路連線** | 零網路（完全隔離） | 負責發起 HTTP/Web 查詢取得官方資訊 | 嚴禁在 MCP 內部實作爬蟲或外網請求 |
| **計算邏輯** | 唯一的計算權威 | 轉發並展示 MCP 計算結果 | 嚴禁 Agent 自行估算或覆寫計算金額 |
| **實體辨識** | 產生權威 ID (`mch_`, `ev_`, `fact_`) | 提供候選比對與使用者確認引導 | 嚴禁未經確認進行 Fuzzy Auto-Accept |
| **匯率換算** | 依據輸入的 `FxSnapshot` 精確計算 | 取得官方即時匯率並量化為 `ratePpm` | 嚴禁預設 1:1 匯率回退 |
| **隱私安全** | 攔截任何含卡號/CVV/密碼之請求 | 遮蔽或引導使用者移除敏感欄位 | 嚴禁儲存或傳輸 PAN, CVV, OTP, 密碼 |
| **多租戶隔離** | 藉由 `--data-dir` 與檔案鎖強制隔離 | 傳遞正確的租戶路徑 | 嚴禁多使用者共用同一個資料目錄 |

## 3. 資料儲存與併發控制 (Storage & Concurrency)

1. **使用者目錄隔離**：每個使用者必須配置獨立的絕對路徑資料目錄（例如 `/data/users/user_123/`）。
2. **行程排他鎖 (Exclusive Lock)**：MCP 伺服器啟動時於資料目錄建立 `card-rewards.lock`。若已有其他行程佔用，立即回傳 `LOCK_EXISTS` 錯誤退出，防止併發寫入損壞帳本。
3. **冪等性保障 (Idempotency)**：記帳工具（`record_transaction`）必須提供 `idempotencyKey`，防止網路波動或代理人重試造成重複扣減上限。
