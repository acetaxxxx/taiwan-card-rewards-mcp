# 使用者信用卡與權益設定檢核清單 (User Config Checklist)

使用者在初次使用或每月初維護時，可透過本清單與 Agent 進行持卡與權益對齊：

---

## 1. 持卡清冊登記 (`register_card`)

- [ ] **主力一般消費卡** (例如：富邦 J 卡、聯邦賴點卡、國泰 CUBE 卡)
- [ ] **網購 / 行動支付專用卡** (例如：台新 @GoGo 卡、玉山 U Bear 卡、永豐 SPORT 卡)
- [ ] **海外旅遊 / 外幣消費卡** (例如：富邦 J 卡日韓版、聯邦吉鶴卡、永豐幣倍卡)
- [ ] **生活繳費 / 交通專用卡** (例如：遠東樂家+ 卡、一卡通聯名卡)

---

## 2. 動態權益方案確認 (`upsert_user_benefit_status`)

- [ ] **國泰世華 CUBE 卡當日權益方案**：
  - [ ] 玩數位 (網購、串流)
  - [ ] 樂響購 (百貨、餐廳、KTV)
  - [ ] 趣旅行 (機票、飯店、海外)
  - [ ] 集精選 (超商、加油、高鐵)
  - [ ] 慶生月 (指定壽星加碼)
- [ ] **台新 Richart / 數位帳戶自扣扣款加碼資格**：已完成綁定確認
- [ ] **永豐大戶 / 幣倍超匯資格**：已達指定資產門檻

---

## 3. 每月 / 週期活動登錄確認

- [ ] **銀行每月滿額登錄活動**（若適用，記錄登錄序號或已登錄狀態）
- [ ] **指定通路登錄加碼**
