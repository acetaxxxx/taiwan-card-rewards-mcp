# User-assisted image offer ingestion

The system supports both image or image-URL input and structured user input when a bank publishes an offer in a non-machine-readable image, but the MCP boundary accepts only the structured candidate JSON produced by the agent or UI. User-provided transcription is stored as candidate input with source provenance and a content fingerprint; it is not official evidence and cannot activate a rule until a traceable official source URL, page, announcement identifier, or source description plus the offer period, reward conditions, exclusions, reward unit, and cap are reviewed and the user explicitly confirms them. Raw images are not retained by default, reducing sensitive-data exposure while preserving enough provenance to audit the candidate.
