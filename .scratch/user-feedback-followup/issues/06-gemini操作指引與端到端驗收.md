# 06: Gemini 操作指引與端到端驗收

**What to build:** Gemini 3.8 Flash Medium 取得精簡且明確的 Agent 操作指引，能從商家名稱解析與直接推薦開始，完成優惠更正、指定支付服務路徑、交易回溯與 FX 重用流程。端到端 trace 驗證低推理模型在真實工具互動中的完成條件與停止條件。

**Blocked by:** 02: 使用者確認私有優惠版本; 03: 統一交易記錄與時間查詢; 04: 由優惠細則生成付款路徑; 05: 相容鍵匯率重用與路徑成本.

**Status:** ready-for-agent

- [ ] 指引採少於 1,500 tokens 的三層結構，僅在使用者確認、selector、FX 與交易查詢等高風險決策提供精確 payload 或決策表。
- [ ] Agent 能從使用者自然語言的商家名稱與消費意圖直接呼叫 merchant resolution 與 `recommend`，對歧義只提出必要問題，不要求先列出卡片或付款路徑。
- [ ] Agent 能在使用者更正時遵守「差異預覽 → 確認 → 寫入」，不口頭承認後遺失狀態，也不未確認直接覆寫。
- [ ] stdio MCP trace 覆蓋商家名稱解析、歧義處理、直接推薦、指定支付清單產生路徑、跨卡 FX 重用、四種資金來源交易與兩種時間依據查詢。
- [ ] 外部來源失敗時，Agent 停止無效重試，交付可用結果、估算標記與結構化缺口。
- [ ] deterministic public-contract 測試與實際低推理模型 trace 分開保存並分別報告結果。
